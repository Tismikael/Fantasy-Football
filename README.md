# Fantasy Football

### Summary
Fantasy Football is a web application that allows users to create fantasy teams for the English Premier League. 

### Features
- **User Account**: Registration, login
- **Team Setup**: Players selection from pool of latest EPL season, squad creation within money bounds
- **LeaderBoard**: View top 10 users based on squad performance.

### Tech Stack
- React
- Tailwind CSS
- Supabase DB
